# Что нового

## 0.1 — 27.10.2026

- Первая версия Fervo TV
- Плейлисты M3U / M3U8 по ссылке или из файла, Xtream Codes API (Live TV)
- Воспроизведение HLS, MPEG-TS и MP4
- Категории, поиск, каналы карточками с логотипами
- Автоподгрузка логотипов из базы iptv-org, подложка подбирается под каждый логотип
- Плеер во весь экран: переключение каналов свайпом и кнопками пульта
- Управление пультом на Android TV и касаниями на телефоне
- Настройки и раздел «О приложении»
