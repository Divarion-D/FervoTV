# Что нового

## 0.1.3 — 04.11.2026

- Обновлены элементы управления плеером для вертикального и горизонтального экрана
- Добавлены выбор звука и субтитров, таймер сна, масштаб, скорость и сведения о потоке
- Улучшены восстановление воспроизведения, обработка форматов и навигация крестовиной на ТВ
- Исправлены перекрытие плеера предпросмотром, возврат из полного экрана и сохранение фокуса
- Настройки сгруппированы, главную страницу можно отключить, ссылка на репозиторий всегда видна
- После обновления предложение «Что нового» сохраняется до ответа пользователя

## 0.1.2 — 31.10.2026

- Исправлена проверка разрешения на установку обновления APK

## 0.1.1 — 31.10.2026

- Проверка новой версии на GitHub и показ изменений перед обновлением
- Скачивание APK с проверкой свободного места и запуск системного установщика Android

## 0.1.0 — 27.10.2026

- Плейлисты M3U / M3U8 по ссылке или из файла, Xtream Codes API (Live TV)
- Сохранённый список каналов, автообновление и понятные сообщения об ошибках сети
- Эфир с категориями, поиском, избранным, недавними каналами и предпросмотром
- Навигация пультом на Android TV и касаниями на телефоне; полноэкранный плеер
- Телегид, фильмы и сериалы с поиском, продолжением просмотра и историей
- Файл настроек, русский и английский интерфейс, раздел «О приложении» и лицензии
