# Что нового

## 0.2 — в разработке

- Плейлист сохраняется на устройстве: список каналов открывается сразу и работает без интернета
- Настройка «Автообновление»: при каждом запуске, каждые 6 часов, раз в день, раз в неделю или только вручную
- Кнопка «Обновить плейлист сейчас» в настройках
- При первом запуске без сети можно сразу перейти в настройки и сменить плейлист
- Понятные сообщения об ошибках сети
- Каналы хранятся в базе данных: плейлисты на десятки тысяч каналов загружаются без нехватки памяти, сетка и поиск работают без задержек
- Поиск находит каналы по началу слов названия («мат фут» — «Матч! Футбол»), без разницы между «е» и «ё»
- Автообновление «каждые N дней»; обновление по расписанию срабатывает и тогда, когда приложение открыто долго
- Когда приложение уходит в фон, эфир останавливается и не тратит трафик; при возврате канал идёт с текущего момента
- Каналы переключаются и медиаклавишами «следующий / предыдущий»
- Поиск по категориям, когда их много; кнопка «Назад» в списке сначала очищает поиск
- Длинные названия категорий видны целиком — бегущей строкой
- На ТВ фокус возвращается туда, откуда вы ушли: в настройках — на ту же строку, после настроек — на их кнопку
- Если файл плейлиста больше недоступен, приложение так и скажет и предложит выбрать его заново
- Неверный логин или пароль Xtream — понятное сообщение «аккаунт не принят»
- Без браузера ссылка на GitHub показывается QR-кодом — откройте её на телефоне
- Видео, которое не грузится, больше не крутит загрузку бесконечно: через 20 секунд — сообщение «нет данных», OK — повторить
- Сетка каналов листается плавнее на слабых телефонах
- В разделе «О приложении» — лицензии библиотек
- После обновления приложение предложит посмотреть, что нового
- Подготовка к телегиду: приложение умеет загружать программу передач XMLTV (в том числе сжатую и очень большую — сотни мегабайт без нехватки памяти), брать её адрес из плейлиста или аккаунта Xtream и находить программу для каналов по коду и названию; экраны появятся в следующих версиях
- Номера каналов берутся из плейлиста (`tvg-chno`) и от Xtream-провайдера
- Подготовка к избранному, скрытию, переименованию, своему порядку и подборкам каналов: эти настройки будут храниться так, что обновление плейлиста их не сбросит
- Новый раздел «Эфир» для телевизора: боковое меню, категории со «Избранным», «Недавними» и подборками, каналы строками с текущей передачей и полосой прогресса, окно предпросмотра рядом со списком, часы, подсказки кнопок пульта
- Канал начинает играть в окне, когда на нём задерживается фокус (на телефоне — по нажатию); OK или второе нажатие открывает его во весь экран без перезапуска, после выхода он продолжает играть в окне. Превью и его звук выключаются в настройках
- Под окном — текущая передача с описанием и две следующие; ▶ на канале открывает его расписание
- Меню канала (долгий OK, клавиша Menu или долгое нажатие): избранное, подборки, переименование, скрытие. Меню категории: переименовать, скрыть, «Вернуть как в плейлисте», новая подборка, «Показать скрытое»
- Порядок каналов: как у провайдера, по номеру, по названию, сначала с архивом, сначала избранные
- Вид «список / плитки»; на плитках — полоса прогресса передачи под логотипом
- Во весь экран: набор номера канала цифрами пульта, клавиша Last/Recall — предыдущий канал, часы в углу
- CH+/CH− в списках листают по 10 строк, долгое нажатие — в начало или конец
- Раздел открывается на последней категории и канале, и после перезапуска (можно выключить в настройках)
- Выход из приложения кнопкой «Назад» — только по второму нажатию
- Значок «нет сети»; без сети обновление плейлиста ждёт подключения и запускается само; обновление плейлиста и подбор логотипов видны маленькой плашкой внизу
- Логотипы каналов рисуются одной готовой картинкой вместе с подложкой: списки листаются легче
- Телегид сеткой: каналы по строкам, передачи по времени, линия «сейчас»; открывается на текущем времени. Пульт: ▲▼ — каналы, ▶ — к передачам строки, ◀▶ — по передачам, долгий OK — меню передачи или канала
- Над сеткой — окно видео и описание передачи под курсором; первый OK на канале включает его в окне, второй — во весь экран
- Инструменты сетки: день, «Сейчас», категория, порядок, «Каналы без программы», «Видео в окне», поиск канала или передачи, сопоставление каналов с телегидом
- Если телегид не подключён, а в плейлисте указан его адрес, — кнопка «Загрузить телегид из плейлиста»; дальше телегид обновляется сам
- В «Эфире» переключатель «Список / Сетка телегида»; в настройках можно выбрать, каким видом раздел открывается
- Во весь экран ◀ открывает каналы текущей категории поверх видео, ещё раз ◀ — все категории; ▶ — недавние каналы с временем просмотра. На телефоне — свайп от левого или правого края
- На телефоне — нижняя панель: «Эфир», «Телегид», «Ещё» (настройки)
