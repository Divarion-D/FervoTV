# 17. Профили (PROF)

### PROF-001 Несколько профилей
- **Суть:** у каждого зрителя свои избранное, история, позиции просмотра, правки категорий, привязки телегида, раскладка и языки.
- **Сценарий:** в семье у каждого свой профиль; ребёнок не видит взрослые каналы, у взрослых — своя история.
- **Критерии приёмки:**
  - источники общие для устройства; к каждому профилю привязывается набор доступных ему источников;
  - удаление профиля спрашивает подтверждение и удаляет только его личные данные;
  - при обновлении существующей установки все текущие данные становятся данными первого профиля.
- **Фаза:** P5
- **Статус:** ⬜ нет

### PROF-002 Имя и аватар
- **Суть:** профиль имеет имя и картинку: одну из встроенных или свою фотографию.
- **Критерии приёмки:**
  - своя картинка — файл на устройстве или фото, отправленное с телефона (BAK-010);
  - картинку можно выбрать сразу при создании профиля и позже при редактировании;
  - аватар виден внизу бокового меню и в шапке экрана «Ещё».
- **Фаза:** P5
- **Статус:** ⬜ нет

### PROF-003 PIN профиля
- **Суть:** профиль можно закрыть 4-значным PIN.
- **Критерии приёмки:**
  - PIN хранится только в виде хэша с солью;
  - три неверных ввода подряд — пауза 30 с;
  - сброс PIN другим профилем без PIN-а невозможен; забытый PIN сбрасывается только очисткой данных приложения (это сказано в тексте при установке PIN).
- **Фаза:** P5
- **Статус:** ⬜ нет

### PROF-004 Выбор и смена профиля
- **Суть:** при запуске — экран выбора профиля (если профилей больше одного), смена — без выхода из приложения.
- **Критерии приёмки:**
  - экран выбора при запуске можно отключить: тогда открывается последний профиль;
  - переключение доступно из бокового меню (долгий OK на аватаре) и из экрана «Ещё».
- **Фаза:** P5
- **Статус:** ⬜ нет

### PROF-005 Детский профиль
- **Суть:** профиль, в котором скрыто содержимое для взрослых.
- **Критерии приёмки:**
  - скрытие действует везде: эфир, фильмы, сериалы, главная, поиск, архив, загрузки, рекомендации лаунчера и прямой запуск по ссылке;
  - взрослые категории распознаются по словам-маркерам на нескольких языках с исключениями для детских каналов с похожими словами в названии; результаты TMDB для взрослых исключаются;
  - сетка телегида в детском профиле скрыта;
  - выйти из детского профиля в другой можно только через PIN этого другого профиля, если он задан.
- **Фаза:** P5
- **Статус:** ⬜ нет

### PROF-006 PIN на управление категориями
- **Суть:** экран управления категориями (скрытие, переименование) можно закрыть PIN, чтобы скрытое не вернули без спроса.
- **Критерии приёмки:**
  - PIN хранится хэшем с солью; запрашивается при входе в экран управления и при действиях «показать скрытое».
- **Фаза:** P5
- **Статус:** ⬜ нет

### PROF-007 Что открывается при запуске
- **Суть:** для каждого профиля выбирается стартовый экран.
- **Критерии приёмки:**
  - варианты: главная; последний канал во весь экран; последний канал в сетке телегида; последний канал в разделе эфира (категория канала, фокус и превью на нём); избранные каналы; выбранный канал из списка с поиском;
  - если стартовый канал недоступен (источник удалён), открывается главная с сообщением.
- **Фаза:** P5
- **Статус:** ⬜ нет
