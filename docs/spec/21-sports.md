# 21. Спорт (SPORT)

Результаты и расписание матчей из публичного источника спортивных данных (например, открытого API
ESPN) и поиск каналов, которые показывают матч, в собственном телегиде пользователя. Видео из
спортивного источника не берётся; данные плейлиста с устройства не уходят.

### SPORT-001 Раздел «Спорт»
- **Суть:** раздел бокового меню с текущими счетами, матчами сегодня и завтра.
- **Критерии приёмки:**
  - ряды: «Идут сейчас» (с меткой прямого эфира), «Спорт на ваших каналах» (по телегиду), «Скоро»;
  - OK на матче открывает его страницу;
  - пока ничего не выбрано (SPORT-002), раздел объясняет, как выбрать лиги.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SPORT-002 Выбор видов спорта и лиг
- **Суть:** в настройках пользователь выбирает виды спорта и лиги, за которыми следит, и любимые команды.
- **Критерии приёмки:**
  - по умолчанию ничего не выбрано; есть вариант «все лиги» с предупреждением о времени загрузки;
  - порядок видов спорта и лиг меняется режимом перемещения; раздел и ряд на главной следуют ему;
  - выбор хранится в профиле.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SPORT-003 Фильтры раздела
- **Суть:** две строки кнопок: виды спорта (и «мои команды») и лиги выбранного вида.
- **Критерии приёмки:**
  - OK включает/выключает кнопку, можно несколько; ни одной — показывается всё;
  - выбор действует до закрытия приложения;
  - кнопка «Обновить» пересобирает данные, ход виден в индикаторе фоновых задач.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SPORT-004 Страница матча
- **Суть:** счёт, время, стадия турнира, стадион с городом и страной; вкладки: хроника, статистика, составы, турнирная таблица, форма команд, трансляции.
- **Критерии приёмки:**
  - во время матча счёт и хроника обновляются автоматически;
  - вкладка трансляций показывает найденные каналы из телегида пользователя (SPORT-005), а ниже — список вещателей из спортивного источника, если он есть.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SPORT-005 Найти каналы с матчем
- **Суть:** поиск в телегиде пользователя каналов, которые показывают этот матч.
- **Критерии приёмки:**
  - доступно с 30 мин до начала до 30 мин после окончания; раньше — страница говорит, когда поиск откроется;
  - найденные каналы — справа, лучшие сверху, с превью; OK — во весь экран, Back — обратно к матчу;
  - фильтр по языку, стране (по префиксу в названии канала), качеству и источнику; «строгий» фильтр скрывает остальные, нестрогий — опускает их вниз; «запомнить» применяет фильтр ко всем матчам;
  - сопоставление выполняется на устройстве.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SPORT-006 Спорт на главной
- **Суть:** необязательный ряд главной с идущими и скорыми матчами выбранных лиг и команд.
- **Критерии приёмки:**
  - включается в настройке главной (HOME-005); OK открывает страницу матча.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SPORT-007 Обновление спортивных данных
- **Суть:** фоновое обновление расписания и быстрое обновление счёта, пока спорт на экране.
- **Критерии приёмки:**
  - пересборка: каждые 1 / 2 / 4 / 8 ч, при запуске или вручную; видно время последнего обновления;
  - счёт идущих матчей обновляется каждые 30–120 с (настройка), только пока открыт спортивный экран или ряд.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SPORT-008 Уведомления о голах
- **Суть:** уведомление о голе в матче любимой команды.
- **Критерии приёмки:**
  - включается в настройках спорта; во время просмотра — ненавязчивая плашка, не перекрывающая субтитры.
- **Фаза:** P6
- **Статус:** ⬜ нет
