# 14. Фильмы и сериалы (VOD)

Видеотека провайдера: просмотр каталога, страницы фильмов и сериалов, продолжение просмотра.
Откуда берутся данные — SRC-010, SRC-011, SRC-019; обогащение постерами и описаниями — `20-metadata.md`.

### VOD-001 Разделы «Фильмы» и «Сериалы»
- **Суть:** два раздела бокового меню с категориями провайдера слева и каталогом справа.
- **Пульт:** ◀ из каталога — к категориям. **Сенсор:** на телефоне категории — полосой кнопок.
- **Критерии приёмки:**
  - служебные категории: «Избранное», «Недавние», «Все»;
  - раздел без данных скрыт из бокового меню (при динамическом меню, UI-007);
  - каталог на 150 000 фильмов открывается и листается без задержек (постраничная выдача).
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.2: разделы в боковом меню и на нижней панели только при наличии фильмов/сериалов у источника; «Избранное», «Недавние», «Все», подборки, категории; каталог постранично из базы; 150 000 на устройстве в интерфейсе не замерялись — только тестом данных; на TV с пультом не проверено)

### VOD-002 Постеры сеткой или списком
- **Суть:** переключатель вида каталога: сетка постеров или компактный список.
- **Критерии приёмки:**
  - в сетке: постер, название, год, отметка просмотра/прогресс;
  - в списке: маленький постер, название, год, жанр, рейтинг, длительность;
  - выбранный вид запоминается для раздела.
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.2: сетка постеров — постер, название, год, прогресс или галочка; список — маленький постер, название, год, жанр, рейтинг; длительность в списке — только у начатых: в списке провайдера её нет; вид запоминается для раздела)

### VOD-003 Сортировка каталога
- **Суть:** как у провайдера, по названию, по дате добавления (новые сверху), по году, по рейтингу.
- **Критерии приёмки:**
  - сортировка запоминается для раздела;
  - сортировка по дате добавления использует дату от провайдера, при её отсутствии — дату первого появления в Fervo TV.
- **Фаза:** P2
- **Статус:** ✅ готово (P2.2: как у провайдера, по названию, недавно добавленные, по году, по рейтингу; запоминается для раздела; дата добавления — провайдера или первого появления)

### VOD-004 Карточка фильма
- **Суть:** подробности о фильме рядом с каталогом или отдельной страницей.
- **Критерии приёмки:**
  - постер, название, год, жанры, длительность, рейтинг, описание (от провайдера или TMDB, META-004);
  - кнопки: «Смотреть» или «Продолжить с N:NN», «С начала», «В избранное», «Скачать» (DL-001), «Трейлер» (если есть);
  - на телефоне — отдельная страница с прокруткой.
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.2: постер, чистое название, год, жанр, длительность, рейтинг, метки, описание, режиссёр и актёры Xtream (get_vod_info); «Смотреть» / «Продолжить с N:NN» и «С начала», «В избранное», меню; на телефоне — отдельная страница; «Скачать» — с DL-001, «Трейлер» и описание из TMDB — с META)

### VOD-005 Страница сериала
- **Суть:** фон сериала, описание, сезоны и эпизоды.
- **Сценарий:** OK на сериале — открывается его страница с фокусом на кнопке продолжения.
- **Критерии приёмки:**
  - кнопки: «Продолжить S1·E2» / «Смотреть», «В избранное», «Скачать сезон», меню сериала;
  - вкладки сезонов с числом эпизодов; спецвыпуски (сезон 0) — последней вкладкой и не входят в общий счёт;
  - эпизоды сеткой или списком: кадр, номер, название, дата выхода, длительность, описание, прогресс;
  - сериал открывается на последнем просмотренном эпизоде; не начатый — с первого эпизода первого сезона;
  - ошибка загрузки эпизодов показывает код ответа и совет (см. SRC-011).
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.2: фон, описание, «Продолжить S1 · E2» / «Смотреть», «В избранное», меню сериала; вкладки сезонов с числом эпизодов, спецвыпуски последними и вне общего счёта; эпизоды списком с кадром, номером, названием, датой, длительностью, описанием и прогрессом; открывается на последнем просмотренном; ошибка — код ответа и совет; «Скачать сезон» — с DL-001; вида «сеткой» для эпизодов нет)

### VOD-006 Порядок эпизодов и скрытие просмотренных
- **Суть:** сезоны и эпизоды «сначала старые» или «сначала новые», скрытие просмотренных эпизодов.
- **Критерии приёмки:**
  - настройка хранится для каждого сериала в профиле.
- **Фаза:** P2
- **Статус:** ✅ готово (P2.2: «Сначала новые» и «Скрывать просмотренные эпизоды» в меню сериала, хранятся для каждого сериала на устройстве; профилей пока нет, в файл настроек не попадает)

### VOD-007 Чистые названия
- **Суть:** из названий эпизодов убирается повтор названия сериала и номера, из заголовков страниц — служебные метки провайдера в начале.
- **Критерии приёмки:**
  - «Сериал – S01E03 – Название» показывается как «Название»; если после чистки пусто — берётся название из TMDB или «Эпизод 3»;
  - метки вида `|EN|`, `[4K]` в начале заголовка страницы убираются, подписи постеров остаются как у провайдера.
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.1 данные + P2.2 экраны: на страницах — чистое название с годом и метками, на постерах — подпись провайдера; пустое название эпизода — «Эпизод N»; названия из TMDB — с META)

### VOD-008 Отметки просмотра
- **Суть:** видно, что досмотрено, а что начато.
- **Критерии приёмки:**
  - просмотр до 95% длительности отмечает элемент просмотренным (галочка), меньше — полоса прогресса;
  - постер сериала показывает прогресс последнего начатого эпизода;
  - «Отметить просмотренным / непросмотренным» в меню — для фильма, эпизода, сезона.
- **Фаза:** P2
- **Статус:** ✅ готово (P2.1 данные + P2.2 экраны: галочка на постере и эпизоде, полоса прогресса; у сериала — прогресс последнего начатого эпизода; «Отметить просмотренным / непросмотренным» для фильма, эпизода и сезона)

### VOD-009 Автопродолжение следующей серии
- **Суть:** в конце эпизода начинается следующий, в том числе следующего сезона.
- **Критерии приёмки:**
  - за 30 с до конца появляется карточка с обратным отсчётом, «Смотреть сейчас» и «Отмена»;
  - после последнего сезона — спецвыпуски, затем остановка;
  - выключается настройкой (общей для сериалов и архива, CU-006).
- **Фаза:** P2
- **Статус:** ✅ готово (P2.2: за 30 с до конца — карточка с отсчётом, «Смотреть сейчас» (OK) и «Отмена» (Back); через сезоны, затем спецвыпуски, затем остановка; настройка «Следующий эпизод автоматически» — архив (CU-006) подключится к ней в P4)

### VOD-010 Продолжение с места
- **Суть:** фильмы и эпизоды запоминают позицию остановки.
- **Критерии приёмки:**
  - настройка: продолжать сразу / спрашивать / всегда с начала (по умолчанию «спрашивать»);
  - позиция сохраняется при выходе, сворачивании, сне устройства и падении приложения (периодически во время просмотра);
  - позиция последних 10 с перед концом не сохраняется — элемент считается просмотренным.
- **Фаза:** P2
- **Статус:** ✅ готово (P2.2: настройка «продолжать / спрашивать / с начала», по умолчанию «спрашивать»; позиция сохраняется при выходе, уходе в фон, смене эпизода и каждые 10 с во время просмотра; последние 10 с — «просмотрено»)

### VOD-011 Избранное и скрытие в видеотеке
- **Суть:** фильмы и сериалы можно добавить в избранное или скрыть.
- **Критерии приёмки:**
  - избранное — служебная категория раздела и ряды на главной (HOME-003);
  - скрытый элемент не виден ни в каталоге, ни в поиске, ни на главной; вернуть — в экране управления.
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.2: «В избранное» / «Скрыть» в меню, служебная категория «Избранное», «Показать скрытые» в меню категории и «Показать» на элементе; ряды на главной и общий поиск — P2.3)

### VOD-012 Управление категориями видеотеки
- **Суть:** скрытие, переименование, порядок, подборки и возврат к виду провайдера — как в эфире (LIVE-012…LIVE-015).
- **Критерии приёмки:**
  - все правила LIVE-012…LIVE-015 выполняются для фильмов и сериалов.
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.2, как в эфире: переименование, скрытие, «Вернуть как у провайдера» со списком изменений, подборки, «Показать скрытые»; режима перемещения (LIVE-013) и экрана управления нет — как и в эфире)

### VOD-013 Меню фильма и сериала
- **Суть:** долгий OK на постере — меню: смотреть, библиотека (избранное, скачать, отметить), организация (скрыть, переместить, переименовать), подробности.
- **Пульт:** долгий OK или Menu. **Сенсор:** долгое нажатие.
- **Критерии приёмки:**
  - у эпизода — своё меню (смотреть, скачать, отметить просмотренным);
  - пункты метаданных (META-005) появляются при включённом TMDB.
- **Фаза:** P2
- **Статус:** 🟡 частично (P2.2: долгий OK / Menu / долгое нажатие — смотреть, подробнее; библиотека — избранное, отметка, подборки; организация — скрыть, переименовать; у эпизода — смотреть, с начала, отметить; «Скачать», «Переместить» и пункты метаданных — с DL-001, LIVE-013 и META-005)

### VOD-014 Несколько версий одного фильма
- **Суть:** если у провайдера один фильм есть в нескольких вариантах (качество, язык), они объединяются.
- **Критерии приёмки:**
  - объединение по ID TMDB, при его отсутствии — по нормализованному названию и году;
  - на карточке — «Версии (N)» со списком: метки качества и языка из названий, источник.
- **Фаза:** P6
- **Статус:** ⬜ нет

### VOD-015 Трейлеры
- **Суть:** трейлер из TMDB воспроизводится внутри приложения.
- **Пульт:** OK — пауза, ◀▶ — на 10 с.
- **Критерии приёмки:**
  - если трейлер недоступен, пробуется следующий; если не вышло ни одного — предложение открыть во внешнем приложении.
- **Фаза:** P6
- **Статус:** ⬜ нет

### VOD-016 Полноэкранный вид каталога
- **Суть:** альтернативный вид видеотеки: фон выбранного фильма на весь экран, сверху его название, год, рейтинг, описание и актёры, ниже — сетка постеров.
- **Критерии приёмки:**
  - выбор вида — в настройках раскладки (UI-019); общий для фильмов и сериалов;
  - область описания фокус не получает: OK на постере — смотреть/открыть, долгий OK — меню;
  - категории открываются панелью по ◀;
  - высота области описания настраивается, 0% — только постеры.
- **Фаза:** P6
- **Статус:** ⬜ нет
