# 31. Настройки (SET)

Устройство экрана настроек и сквозные настройки. Настройки отдельных функций описаны в их записях
(например, PLR-021, EPG-003) и появляются в соответствующей группе.

### SET-001 Экран «Настройки»
- **Суть:** список настроек с переключателями и выбором; открывается кнопкой рядом с поиском (с P2 — из «Ещё»).
- **Критерии приёмки:**
  - есть пункты: источник плейлиста, автообновление, «Обновить сейчас» со временем и итогом последнего обновления, автоподбор логотипов и адрес базы логотипов;
  - каждая настройка сохраняется сразу и переживает перезапуск.
- **Фаза:** P0
- **Статус:** ✅ есть

### SET-002 Значения по умолчанию в одном месте
- **Суть:** все дефолты и настраиваемые константы (сеть, тайминги интерфейса, пороги жестов, сроки кэшей) собраны в одном файле ядра.
- **Критерии приёмки:**
  - в коде нет «магических чисел» для того, что есть в этом файле;
  - новая настройка = поле настроек + дефолт в этом файле + строка в экране настроек.
- **Фаза:** P0
- **Статус:** ✅ есть

### SET-003 О приложении
- **Суть:** версия и номер сборки (отметка debug-сборки), автор, ссылка на репозиторий, лицензии и благодарности внешним сервисам.
- **Критерии приёмки:**
  - версия читается из установленного пакета;
  - если браузера нет (частый случай на приставках), ссылка показывается текстом и QR-кодом.
- **Фаза:** P0
- **Статус:** 🟡 частично (сделано: версия из пакета, автор, ссылка; без браузера — QR-код и текст; лицензии библиотек и благодарность iptv-org; на устройстве не проверено)

### SET-004 Что нового
- **Суть:** журнал изменений внутри приложения, тот же файл, что описание релиза.
- **Критерии приёмки:**
  - версии по убыванию, текущая сверху;
  - после обновления приложения при первом запуске предлагается посмотреть изменения.
- **Фаза:** P0
- **Статус:** 🟡 частично (сделано: экран и предложение посмотреть изменения после обновления; на устройстве не проверено)

### SET-005 Группы настроек с пояснениями
- **Суть:** настройки разбиты на группы-карточки (Источники и телегид, Эфир, Плеер, Изображение, Звук и субтитры, Просмотр и запись, Оформление, Раскладка, Метаданные, Профили, Приложение); внутри группы — строки слева и панель пояснения справа.
- **Критерии приёмки:**
  - на карточке группы — число настроек;
  - панель пояснения: что делает настройка, варианты и отмеченный рекомендуемый;
  - переключатели и короткие списки меняются прямо в строке (OK или ◀▶); длинные списки и числа — в панели справа, без всплывающих окон; стрелка «›» — только у строк, открывающих отдельную страницу;
  - возврат с подстраницы ставит фокус на ту же строку;
  - на телефоне — обычный список групп и строк, пояснение под строкой.
- **Фаза:** P2
- **Статус:** ⬜ нет

### SET-006 Поиск по настройкам
- **Суть:** поле поиска находит настройку по названию и показывает путь к ней и текущее значение.
- **Критерии приёмки:**
  - OK на результате открывает группу с фокусом на настройке.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SET-007 Закреплённые настройки
- **Суть:** долгий OK на любой настройке добавляет её в группу быстрых настроек в начале списка.
- **Критерии приёмки:**
  - у закреплённой строки подписано, из какой она группы; открепление — долгим OK;
  - закреплённые настройки — в профиле.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SET-008 Сеть: DNS и прокси
- **Суть:** свой DNS для всего приложения и HTTP-прокси.
- **Критерии приёмки:**
  - DNS: системный, несколько публичных (Google, Cloudflare, Quad9), DNS-over-HTTPS со своим адресом;
  - прокси: адрес, порт, логин и пароль (пароль — в защищённом хранилище);
  - применяется к источникам, телегиду, логотипам, метаданным и потокам.
- **Фаза:** P6
- **Статус:** ⬜ нет

### SET-009 Сброс запомненного плеером
- **Суть:** раздельный сброс того, что плеер запомнил для элементов: движок, масштаб, громкость, задержка звука, выбор дорожек.
- **Критерии приёмки:**
  - у каждой кнопки сброса указано число сохранённых значений;
  - отдельный сброс выборов движка только для эфира.
- **Фаза:** P3
- **Статус:** ⬜ нет

### SET-010 Настройки отдельного источника
- **Суть:** часть настроек переопределяется для одного источника: порядок движков, задержка эфира, предбуфер, «сдаться через», часовой пояс архива, User-Agent и Referer, интервал обновления.
- **Критерии приёмки:**
  - в строке настройки видно, что для какого-то источника есть переопределение;
  - «Как в общих настройках» убирает переопределение.
- **Фаза:** P4
- **Статус:** ⬜ нет

### SET-011 Списки и навигация
- **Суть:** для каждого раздела (эфир, фильмы, сериалы) — запоминать ли последнюю категорию и элемент.
- **Критерии приёмки:**
  - по умолчанию запоминание включено везде;
  - при выключенном раздел открывается на первой категории сверху.
- **Фаза:** P1
- **Статус:** ⬜ нет
