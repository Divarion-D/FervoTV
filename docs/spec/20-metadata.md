# 20. Метаданные (META)

Логотипы каналов, постеры, описания, актёры, трейлеры и субтитры из внешних сервисов.

### META-001 Автоподбор логотипов
- **Суть:** если у канала нет логотипа или он не загрузился, логотип ищется в открытой базе iptv-org: сначала по `tvg-id`, затем по нормализованному названию.
- **Критерии приёмки:**
  - база читается потоково; на устройстве хранятся только совпавшие с каналами логотипы, остальное отбрасывается;
  - подбор повторяется при смене плейлиста и раз в 7 дней; если пересобрать не удалось, используется прежний результат;
  - подбор стартует сразу после появления списка, а не после отрисовки сетки;
  - выключается в настройках; адрес базы меняется в настройках с кнопкой «По умолчанию»;
  - порядок: логотип источника → логотип из базы → инициалы.
- **Фаза:** P0
- **Статус:** ✅ есть

### META-002 Подложка логотипа
- **Суть:** фон под логотипом подбирается по его пикселям, чтобы любой логотип был читаем.
- **Критерии приёмки:**
  - непрозрачный логотип — фон цвета его краёв; тёмный — светлый градиент; светлый или цветной — градиент в его основной цвет; без логотипа — фирменный градиент с инициалами;
  - результат кэшируется по адресу картинки.
- **Фаза:** P0
- **Статус:** ✅ есть

### META-003 Битые логотипы
- **Суть:** адреса и серверы, отвечающие ошибкой, временно не запрашиваются.
- **Критерии приёмки:**
  - адрес с ответом 4xx не запрашивается 7 дней;
  - сервер после трёх ответов 4xx без единой удачи пропускается до конца запуска;
  - сетевые сбои (таймаут, нет сети) не запоминаются;
  - логотипы запрашиваются с User-Agent приложения.
- **Фаза:** P0
- **Статус:** ✅ есть

### META-004 Описания и постеры из TMDB
- **Суть:** фильмы, сериалы и эпизоды дополняются постерами, фонами, описанием, жанрами, рейтингом, актёрами с фото и трейлерами из TMDB.
- **Критерии приёмки:**
  - режим: только провайдер / провайдер + TMDB / только TMDB;
  - язык метаданных выбирается отдельно от языка интерфейса;
  - подгрузка фоновая, очередью, с кэшем; каталог из 150 000 фильмов не блокирует интерфейс, видимые элементы — в приоритете;
  - уже полученные в этом сеансе данные показываются мгновенно;
  - на экране настроек и в «О приложении» — указание, что данные предоставлены TMDB, как требуют условия сервиса.
- **Фаза:** P6
- **Статус:** ⬜ нет

### META-005 Исправление сопоставления
- **Суть:** если TMDB подобрал не то, пользователь задаёт своё название для поиска или просит загрузить заново.
- **Критерии приёмки:**
  - пункты меню элемента: «Указать название для TMDB», «Обновить данные TMDB»;
  - своё название сохраняется в резервной копии.
- **Фаза:** P6
- **Статус:** ⬜ нет

### META-006 Ключ TMDB
- **Суть:** доступ к TMDB по личному ключу пользователя.
- **Критерии приёмки:**
  - ключ вводится в настройках или отправляется с телефона (BAK-010), не набирается пультом посимвольно;
  - если в сборке есть общий ключ, на экране видны его ограничения (запросов в минуту/день) и подсказка завести свой;
  - при исчерпании лимита приложение работает на данных провайдера без ошибок.
- **Фаза:** P6
- **Статус:** ⬜ нет

### META-007 Очистка названий для поиска
- **Суть:** перед поиском в TMDB из названия убираются метки провайдера, качество, язык, год в скобках выделяется отдельно.
- **Критерии приёмки:**
  - «|EN| Фильм (2010) 4K» ищется как «Фильм» с годом 2010;
  - правила покрыты unit-тестами на наборе реальных названий.
- **Фаза:** P6
- **Статус:** ⬜ нет

### META-008 Субтитры из OpenSubtitles
- **Суть:** поиск и загрузка субтитров к фильму или эпизоду по учётной записи пользователя OpenSubtitles.
- **Критерии приёмки:**
  - вход — вводом в настройках или с телефона по QR и PIN;
  - поиск по названию, году, сезону/эпизоду и языкам из PLR-013;
  - скачанные субтитры сохраняются и попадают в резервную копию;
  - в «О приложении» — указание на использование API OpenSubtitles.
- **Фаза:** P6
- **Статус:** ⬜ нет
