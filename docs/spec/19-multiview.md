# 19. Мультиэкран (MV)

Одновременный просмотр нескольких каналов эфира.

### MV-001 Мультиэкран до четырёх каналов
- **Суть:** экран делится на 2–4 плитки, в каждой — свой канал.
- **Сценарий:** вечер футбола: два матча рядом, звук у одного.
- **Критерии приёмки:**
  - функция включается в настройках (по умолчанию выключена); там же — максимум плиток (2–4);
  - открывается с двумя плитками, плитки добавляются по запросу;
  - на устройствах с одним аппаратным видеослоем все плитки показывают картинку (рендер не через несколько поверхностей-оверлеев);
  - если устройство не тянет 4 декодера, предлагается меньше плиток с объяснением.
- **Фаза:** P5
- **Статус:** ⬜ нет

### MV-002 Вход в мультиэкран
- **Суть:** кнопка на панели плеера или пункт «В мультиэкран» в меню канала.
- **Критерии приёмки:**
  - текущий канал становится первой плиткой;
  - выбор канала для пустой плитки — список с категориями, подборками и поиском (листание как LIVE-021).
- **Фаза:** P5
- **Статус:** ⬜ нет

### MV-003 Звук у одной плитки
- **Суть:** звук всегда идёт от одной плитки, она отмечена значком динамика.
- **Пульт:** фокус на плитке + OK — перенести звук. **Сенсор:** тап по плитке.
- **Критерии приёмки:**
  - перенос звука не перезапускает ни один поток.
- **Фаза:** P5
- **Статус:** ⬜ нет

### MV-004 Плитка только со звуком
- **Суть:** плитка отказывается от картинки и оставляет звук (например, комментарий к матчу).
- **Критерии приёмки:**
  - освобождённое место занимают остальные плитки;
  - звуковая плитка может быть источником звука вместо видеоплиток.
- **Фаза:** P5
- **Статус:** ⬜ нет

### MV-005 Ошибки и выход
- **Суть:** плитка, которая не смогла запуститься, объясняет почему; выход останавливает всё.
- **Критерии приёмки:**
  - текст причины в плитке (лимит подключений, недоступный поток, нехватка декодеров);
  - Back закрывает мультиэкран и останавливает все потоки, в фоне ничего не играет.
- **Фаза:** P5
- **Статус:** ⬜ нет

### MV-006 Учёт лимита подключений
- **Суть:** перед добавлением плитки Fervo TV проверяет, хватит ли подключений аккаунта.
- **Критерии приёмки:**
  - при известном лимите (SRC-022) лишняя плитка не запускается, показывается предупреждение;
  - плитки разных источников считаются по лимитам своих источников.
- **Фаза:** P5
- **Статус:** ⬜ нет
