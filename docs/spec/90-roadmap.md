# 90. План по фазам

Фазы идут по порядку; следующая начинается, когда выполнены критерии готовности предыдущей. Внутри
фазы порядок свободный. Во всех фазах действует общее правило: всё со статусом ✅ продолжает работать,
тесты ядра зелёные, CI проходит. Парсеры, хранение данных, правила сопоставления, расписания и контракт
движка подтверждаются тестами ядра и применимыми проверками на телефоне — отдельный прогон на TV для
них не требуется. UI, пульт, аппаратное воспроизведение и явно заданные ресурсные критерии проверяются
на соответствующем устройстве. Проверка ядра не закрывает отсутствующий интерфейс или иной критерий.

Всего функций: 220. Распределение: P0 — 28, P1 — 39, P2 — 33, P3 — 28, P4 — 20, P5 — 38, P6 — 34.

Статусы функций P0–P3: ✅ выполнено, 🟡 частично, ⬜ не реализовано; сверены с карточками спецификации.

реализацию и приёмку, а `Status` — «Запланировано», «В работе», «Ожидает» или «Выполнено».

## P3 Плеер

**Цель:** плеер, который открывает почти любой поток и даёт полный контроль над звуком, субтитрами и картинкой.

**Готовность на 06.11.2026:** 🟡 функциональная реализация независимых P3-возможностей завершена в `core`
и едином `app-tv`, но фаза не принята полностью. Host-тесты не заменяют проверку декодеров, HDMI/ARC,
USB, пульта, PiP, режимов экрана и сторонних плееров на физических устройствах.

**Реализовано и проверено на host:**

- ограниченные по времени повторы, backoff, `Retry-After`, перебор DASH/HLS/progressive и запоминание рабочего формата эфира;
- полная панель эфира/VOD, качество, масштаб/громкость на элемент, дорожки, оформление субтитров, PCM-задержка и DSP;
- Widevine/ClearKey, включая inline ClearKey, определение контейнера, настройки буфера и ограничение качества;
- измеряемые метрики потока, журнал/экспорт с маскированием, общий corner/now-playing, audio-only, таймер конца элемента;
- MediaSession, раздельные настройки внешнего плеера и best-effort передача позиции;
- SET-009: счётчики и раздельный сброс формата, движка, масштаба, громкости, задержки и дорожек.

**Доказанные внешние блокеры:** PLR-012 требует отдельной воспроизводимой сборки Media3 FFmpeg AAR с NDK
и решения по кодекам/лицензии; PLR-014 и passthrough-часть PLR-016 требуют HDMI/ARC и реальных маршрутов
вывода; PLR-017/018 требуют второго backend (например, libmpv), которого в проекте нет. Эти зависимости
не добавлялись без отдельного решения. Аппаратная приёмка остальных 🟡 пунктов проводится после реализации,
по [чеклисту](../P3_PLAYER_DEVICE_CHECKS.md) и [TV-отчёту](../P3_TV_DEVICE_CHECKS.md).

**Проверка:** `make check` — 267 debug host-тестов, 0 ошибок/падений/пропусков, `lintDebug` и универсальный
`app-tv` debug APK; оба GitHub Actions запуска для текущего PR прошли. Это функциональный gate, не hardware acceptance.
ADB на TECNO CH6i подтвердил fullscreen-видео 11/11 synthetic fixtures и активный ненулевой speaker `AudioTrack`
для 9/11; MP2 и DTS дали картинку без звука из-за отсутствующих decoder declarations и остаются блокером PLR-012.

**Функции:** 🟡 SRC-009, 🟡 PLR-005, 🟡 PLR-006, ✅ PLR-007, ✅ PLR-008, 🟡 PLR-009, ✅ PLR-010,
