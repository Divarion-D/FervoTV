# 10. Источники и синхронизация (SRC)

Как пользователь подключает провайдеров, как Fervo TV загружает и обновляет их данные и как ведёт
себя без сети.

### SRC-001 M3U/M3U8 по ссылке
- **Суть:** подключение плейлиста по адресу http/https.
- **Сценарий:** при первом запуске пользователь выбирает M3U, вставляет ссылку и нажимает «Загрузить»; дальше источник открывается сам.
- **Пульт:** поле ввода открывает клавиатуру по OK. **Сенсор:** тап по полю.
- **Критерии приёмки:**
  - без схемы в адресе подставляется `http://`;
  - редиректы, в том числе между http и https, проходят;
  - имя канала — текст после первой запятой вне кавычек; группа — `group-title`, затем `#EXTGRP`, иначе «Без категории»;
  - относительный путь логотипа достраивается от адреса плейлиста.
- **Фаза:** P0
- **Статус:** ✅ есть

### SRC-002 M3U из локального файла
- **Суть:** импорт плейлиста из файла на устройстве или USB-накопителе.
- **Сценарий:** «Выбрать файл» в форме источника открывает системный выбор файла.
- **Критерии приёмки:**
  - файл читается через системный выбор документов, доступ сохраняется между запусками;
  - если доступ к файлу потерян, показывается понятное сообщение и предложение выбрать файл заново.
- **Фаза:** P0
- **Статус:** 🟡 частично (выбор файла есть, на устройстве не проверено)

### SRC-003 Xtream Codes: прямой эфир
- **Суть:** вход по серверу, логину и паролю; загрузка категорий и каналов эфира.
- **Сценарий:** пользователь выбирает Xtream, вводит `http://host:port`, логин, пароль.
- **Критерии приёмки:**
  - неверные учётные данные дают сообщение «аккаунт не принят», а не пустой список;
  - категории и каналы сохраняют порядок провайдера; логотип канала — из ответа сервера;
  - поток по умолчанию MPEG-TS, по флажку — HLS (см. SRC-021).
- **Фаза:** P0
- **Статус:** 🟡 частично (код есть, нет тестового аккаунта)

### SRC-004 Сохранённый список и работа без сети
- **Суть:** последний загруженный список источника открывается мгновенно и работает без интернета.
- **Сценарий:** пользователь включает приставку без сети — каналы на месте, недоступные потоки сообщают об ошибке.
- **Критерии приёмки:**
  - при наличии сохранённого списка экран загрузки не показывается;
  - пустой ответ сервера считается ошибкой и не затирает сохранённое;
  - сохранённое привязано к источнику: другой адрес или аккаунт его не подхватывает;
  - после перехода на БД (P0) поведение то же, данные старого формата переносятся автоматически.
- **Фаза:** P0
- **Статус:** ✅ есть

### SRC-005 Автообновление источника
- **Суть:** обновление данных источника по расписанию и вручную.
- **Сценарий:** в настройках выбирается: при каждом запуске / каждые 6 ч / раз в день / раз в неделю / каждые N дней / только вручную.
- **Критерии приёмки:**
  - сохранённый список показывается сразу при любом варианте, обновление идёт в фоне;
  - «Обновить сейчас» запускает обновление принудительно;
  - ошибка обновления при показанном списке — короткое сообщение и текст в настройках, список остаётся;
  - фокус, категория, поиск и прокрутка при подмене списка не сбрасываются;
  - с P4 расписание задаётся для каждого источника отдельно.
- **Фаза:** P0
- **Статус:** 🟡 частично (все варианты, кроме «каждые N дней»; расписание одно на приложение)

### SRC-006 Потоковый импорт больших источников
- **Суть:** импорт и обновление источников любого размера без нехватки памяти и зависаний интерфейса.
- **Сценарий:** пользователь подключает аккаунт с 50 000 каналов и 150 000 фильмов на приставке с 2 ГБ ОЗУ.
- **Критерии приёмки:**
  - разбор потоковый (см. `01-architecture.md`, §4), данные пишутся в БД пакетами;
  - синтетический M3U на 100 000 записей импортируется в JVM-тесте с кучей 256 МБ;
  - интерфейс во время импорта отзывчив (нет кадров дольше 100 мс по вине импорта);
  - ошибка в одной записи пропускает только её.
- **Фаза:** P0
- **Статус:** ⬜ нет

### SRC-007 Первый запуск и ошибки загрузки
- **Суть:** без сохранённого списка пользователь видит прогресс и выход из любой ситуации.
- **Сценарий:** первый запуск без сети или с неверной ссылкой.
- **Критерии приёмки:**
  - на экране загрузки есть переход в настройки;
  - при ошибке — текст причины и кнопки «Повторить» и «Источник»;
  - отмена редактора источника не перезапускает загрузку.
- **Фаза:** P0
- **Статус:** ✅ есть

### SRC-008 Номера каналов и адрес телегида из M3U
- **Суть:** чтение `tvg-chno` и адреса XMLTV из заголовка плейлиста (`url-tvg`, `x-tvg-url`).
- **Сценарий:** плейлист сам подсказывает номера каналов и где брать программу.
- **Критерии приёмки:**
  - `tvg-chno` сохраняется как номер канала (используется в LIVE-009);
  - адреса телегида из заголовка доступны для EPG-001 («взять из плейлиста»), несколько адресов через запятую разделяются;
  - неизвестные теги по-прежнему пропускаются без ошибок.
- **Фаза:** P1
- **Статус:** ⬜ нет

### SRC-009 Заголовки запросов для потоков
- **Суть:** User-Agent и Referer из `#EXTVLCOPT` и из настроек источника передаются при запросах потока.
- **Сценарий:** провайдер отдаёт поток только с определённым User-Agent или Referer.
- **Критерии приёмки:**
  - `#EXTVLCOPT:http-user-agent` и `http-referrer` применяются к своему элементу;
  - в форме источника есть необязательные поля User-Agent и Referer, они применяются ко всем потокам источника;
  - значение элемента важнее значения источника, значение источника важнее значения по умолчанию.
- **Фаза:** P3
- **Статус:** ⬜ нет

### SRC-010 Фильмы и сериалы из M3U
- **Суть:** записи M3U с пометкой фильма или сериала попадают в видеотеку, а не в эфир.
- **Сценарий:** самодельный плейлист с фильмами и сериями сериалов.
- **Критерии приёмки:**
  - атрибут `type` (фильм/сериал) или признаки VOD-адреса определяют раздел; без признаков — эфир;
  - у сериала название шоу — текст до маркера серии, название эпизода — после;
  - распознаются маркеры вида `S1E5` (с нулями, пробелом, точкой или дефисом между частями), `1x05`, «Season N Episode M» и короткие варианты; сезон 0 — спецвыпуски;
  - эпизоды с одинаковым названием шоу объединяются в один сериал; запись без маркера становится очередным эпизодом.
- **Фаза:** P2
- **Статус:** ⬜ нет

### SRC-011 Фильмы и сериалы Xtream
- **Суть:** загрузка категорий, фильмов, сериалов, сезонов и эпизодов из Xtream.
- **Сценарий:** после подключения Xtream в приложении появляются разделы «Фильмы» и «Сериалы».
- **Критерии приёмки:**
  - категории и списки фильмов/сериалов загружаются при синхронизации, эпизоды — при открытии сериала (с кэшем);
  - ошибка загрузки эпизодов показывает код ответа сервера и совет освободить подключение;
  - адрес воспроизведения строится с правильным расширением контейнера.
- **Фаза:** P2
- **Статус:** ⬜ нет

### SRC-012 Распознавание Xtream в M3U-ссылке
- **Суть:** ссылка вида `…/get.php?username=…&password=…` подключается как Xtream.
- **Сценарий:** пользователь вставил ссылку M3U от Xtream-провайдера и получил разделы видеотеки.
- **Критерии приёмки:**
  - при подтверждении сервером учётной записи источник сохраняется как Xtream;
  - если сервер не подтвердил — источник остаётся M3U без ошибки.
- **Фаза:** P2
- **Статус:** ⬜ нет

### SRC-013 Несколько источников
- **Суть:** список подключённых источников с добавлением, правкой и удалением.
- **Сценарий:** у пользователя два провайдера; он добавляет второй в настройках, не теряя первый.
- **Пульт:** список источников, OK — открыть, контекстное меню — действия.
- **Критерии приёмки:**
  - у каждого источника — название, короткая метка, тип, число каналов/фильмов/сериалов, время последнего обновления;
  - удаление спрашивает подтверждение, показывает прогресс и удаляет только данные этого источника;
  - один источник можно назначить основным.
- **Фаза:** P4
- **Статус:** ⬜ нет

### SRC-014 Показ всех источников или одного
- **Суть:** переключатель в шапке сужает всё приложение до одного источника или объединяет все.
- **Сценарий:** пользователь выбирает «Все источники» или конкретного провайдера; выбор действует во всех разделах.
- **Критерии приёмки:**
  - выбор сохраняется после перезапуска и ничего не удаляет и не перезагружает;
  - в списке переключателя — метка и число каналов каждого источника;
  - когда в разделе активны два и больше источников, у категорий и элементов видна короткая метка источника;
  - из меню переключателя можно обновить выбранный источник или все.
- **Фаза:** P4
- **Статус:** ⬜ нет

### SRC-015 Проверка аккаунта
- **Суть:** запрос состояния учётной записи без импорта.
- **Сценарий:** в форме источника и в его строке есть «Проверить»: активен ли аккаунт, срок, пробный ли, сколько подключений занято из скольких.
- **Критерии приёмки:**
  - проверка ничего не записывает в каталог;
  - срок действия показывается в списке источников для Xtream и Stalker.
- **Фаза:** P4
- **Статус:** ⬜ нет

### SRC-016 Импорт в фоне
- **Суть:** во время большого импорта можно начать пользоваться приложением.
- **Сценарий:** на экране импорта кнопка «Продолжить в фоне», дальше прогресс виден в индикаторе (UI-015).
- **Критерии приёмки:**
  - уже импортированные разделы доступны, пока идут остальные;
  - по завершении — короткое сообщение с итогом (добавлено/обновлено/удалено).
- **Фаза:** P2
- **Статус:** ⬜ нет

### SRC-017 Выбор разделов для синхронизации
- **Суть:** при добавлении Xtream/Stalker для эфира, фильмов и сериалов выбирается: загрузить сразу, загрузить в фоне позже, не загружать.
- **Сценарий:** пользователю нужен только эфир — видеотека не скачивается.
- **Критерии приёмки:**
  - для Stalker по умолчанию эфир сразу, видеотека позже;
  - раздел «не загружать» не появляется в боковом меню (если меню динамическое, UI-007).
- **Фаза:** P4
- **Статус:** ⬜ нет

### SRC-018 Два вида пересинхронизации
- **Суть:** «Обновить» добавляет и изменяет; «Обновить и убрать пропавшее» дополнительно удаляет то, чего у провайдера больше нет.
- **Критерии приёмки:**
  - ни один вариант не трогает избранное, историю, позиции, ручной порядок и правки категорий;
  - элемент, удалённый пользователем из подборки, не возвращается в неё после обновления.
- **Фаза:** P4
- **Статус:** 🟡 частично (есть «Обновить плейлист сейчас» с полной заменой)

### SRC-019 Порталы Stalker/Ministra
- **Суть:** третий тип источника: адрес портала и MAC; для строгих порталов — серийный номер, Device ID, Device ID2, подпись.
- **Сценарий:** пользователь вводит адрес портала и MAC, получает эфир, фильмы и сериалы.
- **Критерии приёмки:**
  - дополнительные поля скрыты в блоке «Дополнительно»;
  - доступен выбор пресета User-Agent приставки;
  - ссылка на поток получается непосредственно перед воспроизведением и при истечении молча запрашивается заново (воспроизведение, загрузка с докачкой, смена движка не обрываются);
  - при отказе входа — подсказка проверить MAC и дату/время устройства;
  - остальные функции (загрузки, метаданные, резервная копия, автообновление, переключатель источников) работают как для Xtream.
- **Фаза:** P4
- **Статус:** ⬜ нет

### SRC-020 Чистка названий каналов
- **Суть:** опция источника убирает из названий префиксы стран (`UK|`, `[US]`, `DE:`), хвостовые теги качества (`HD`, `FHD`, `4K`, `HEVC`) и слова пользователя.
- **Сценарий:** «RU: Первый канал FHD» показывается как «Первый канал».
- **Критерии приёмки:**
  - свои слова задаются списком через `;` и удаляются в начале и конце названия;
  - сопоставление с телегидом использует исходные названия;
  - переименованные вручную каналы сохраняют имя пользователя; избранное и история не теряются;
  - выключение опции возвращает исходные названия при следующем обновлении.
- **Фаза:** P4
- **Статус:** ⬜ нет

### SRC-021 HLS вместо MPEG-TS для Xtream
- **Суть:** флажок источника запрашивает потоки эфира в HLS; рядом — проверка, поддерживает ли сервер HLS на самом деле.
- **Критерии приёмки:**
  - проверка открывает один канал в HLS и сообщает результат, ничего не меняя;
  - флажок можно поменять у сохранённого источника без повторного импорта.
- **Фаза:** P4
- **Статус:** 🟡 частично (флажок HLS при вводе есть, проверки нет)

### SRC-022 Лимит подключений аккаунта
- **Суть:** Fervo TV один раз измеряет, сколько потоков допускает аккаунт, и предупреждает до того, как провайдер откажет.
- **Сценарий:** перед записью или мультиэкраном пользователь видит «займёт 2-е подключение из 2».
- **Критерии приёмки:**
  - замер выполняется при первой синхронизации, когда ничего не играет; при неудаче не сохраняется ничего, а не ошибочное число;
  - значение хранится с источником и попадает в резервную копию;
  - в сведениях об источнике есть значение и «Измерить заново» (с предупреждением, что воспроизведение остановится);
  - при ответе «слишком много подключений» плеер показывает обратный отсчёт и сам повторяет попытку.
- **Фаза:** P5
- **Статус:** ⬜ нет

### SRC-023 Добавление источника с телефона
- **Суть:** форму источника можно заполнить на телефоне (или загрузить M3U-файл с компьютера) через QR-код и PIN (механизм BAK-010).
- **Сценарий:** пароль Xtream не набирается пультом: ТВ показывает QR и PIN, пользователь заполняет форму в браузере телефона, на ТВ остаётся нажать «Импорт».
- **Критерии приёмки:**
  - доступно и при первом запуске, и из настроек источников;
  - данные приходят в форму на ТВ и не импортируются без подтверждения на ТВ.
- **Фаза:** P6
- **Статус:** ⬜ нет
