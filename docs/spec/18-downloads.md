# 18. Загрузки (DL)

Скачивание фильмов и эпизодов для просмотра без сети. Записи эфира — `13-catchup-recording.md`, но
хранятся и показываются здесь же.

### DL-001 Скачивание фильмов и эпизодов
- **Суть:** фильм, эпизод или целый сезон ставится в очередь загрузки; каналы эфира не скачиваются.
- **Сценарий:** перед поездкой пользователь скачивает сезон сериала на флешку.
- **Критерии приёмки:**
  - «Скачать» в меню и на карточке сразу ставит в очередь и показывает подтверждение;
  - «Скачать сезон» на странице сериала ставит все эпизоды сезона;
  - скачанный элемент воспроизводится из файла без сети, с теми же позициями и отметками просмотра.
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-002 Экран загрузок
- **Суть:** раздел бокового меню с вкладками «Фильмы / Сериалы / Записи».
- **Критерии приёмки:**
  - у вкладок — число элементов; в заголовке — имя накопителя и свободное место; под ним — папка вкладки;
  - группы «Загружается» и «Готово»; в строке — картинка, сведения, путь к файлу, «38% · 5,1 МБ/с · ещё ~7 мин» или состояние (в очереди, пауза, ошибка, готово);
  - на вкладке записей видна ближайшая запланированная запись.
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-003 Управление загрузкой
- **Суть:** пауза, продолжение, повтор, удаление, открытие во внешнем плеере.
- **Пульт:** кнопки действий появляются только у строки в фокусе.
- **Критерии приёмки:**
  - продолжение докачивает с места остановки, если сервер поддерживает диапазоны;
  - удаление спрашивает подтверждение и удаляет файл.
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-004 Загрузка в фоне
- **Суть:** загрузки продолжаются, когда приложение свёрнуто.
- **Критерии приёмки:**
  - системное уведомление с прогрессом;
  - после перезапуска устройства незавершённые загрузки продолжаются.
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-005 Папка загрузок
- **Суть:** пользователь выбирает папку, в том числе на USB-накопителе; внутри — фиксированные подпапки для фильмов, сериалов и записей.
- **Критерии приёмки:**
  - в выборе папки можно создать новую;
  - выбор делается на экране загрузок.
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-006 Ускорение несколькими соединениями
- **Суть:** загрузка начинается одним соединением и добавляет новые (до 8), пока это ускоряет, но не больше лимита подключений источника.
- **Критерии приёмки:**
  - файл пишется по порядку, чтобы медленная флешка успевала;
  - на однопоточном аккаунте используется одно соединение.
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-007 Понятные ошибки загрузки
- **Суть:** неудачная загрузка объясняет причину и показывает код сервера.
- **Критерии приёмки:**
  - различаются: аккаунт занят другим потоком, сервер отклонил ссылку, связь потеряна, не хватает места, файл больше 4 ГБ на накопителе FAT32 (с советом отформатировать в exFAT);
  - у ошибки есть «Повторить».
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-008 Пропавший файл и извлечённый накопитель
- **Суть:** если файл готовой загрузки или записи исчез, строка помечается «файл отсутствует» и предлагает только удаление.
- **Критерии приёмки:**
  - пока выбранный USB-накопитель отсутствует, новые загрузки и записи идут во внутреннюю папку приложения, экран это сообщает; после подключения — снова в выбранную;
  - загрузка, прерванная извлечением накопителя, помечается ошибкой, а не теряется.
- **Фаза:** P5
- **Статус:** ⬜ нет

### DL-009 Однопоточный аккаунт: смотреть или качать
- **Суть:** если аккаунт допускает один поток, а идёт загрузка, при запуске просмотра Fervo TV спрашивает, что важнее.
- **Критерии приёмки:**
  - варианты: «Приостановить загрузку и смотреть» / «Продолжить загрузку» (плеер закрывается), «Больше не спрашивать»;
  - ответ меняется в настройках на экране загрузок;
  - загрузка, начатая во время просмотра, ждёт окончания просмотра;
  - превью эфира не запускается, пока загрузка занимает единственный поток.
- **Фаза:** P5
- **Статус:** ⬜ нет
