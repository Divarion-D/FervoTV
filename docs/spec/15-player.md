# 15. Плеер (PLR)

Полноэкранное воспроизведение эфира, архива, фильмов и эпизодов. Устройство движков — `01-architecture.md`, §6.

### PLR-001 Базовое воспроизведение
- **Суть:** HLS, MPEG-TS и MP4 через Media3 ExoPlayer.
- **Критерии приёмки:**
  - тип определяется по расширению; ссылка без расширения, не открывшаяся как файл, один раз пробуется как HLS;
  - отставание от окна эфира — автоматический возврат к эфиру;
  - прочие ошибки — текст в плеере, OK повторяет попытку.
- **Фаза:** P0
- **Статус:** ✅ есть (HLS, MPEG-TS и MP4 проверены на устройстве; буферизация без прогресса `Defaults.BUFFER_STALL_TIMEOUT_MS` — ошибка с повтором)

### PLR-002 Жизненный цикл
- **Суть:** плеер ведёт себя как приложение для ТВ: не гаснет экран, не перезапускается поток.
- **Критерии приёмки:**
  - экран не гаснет во время воспроизведения;
  - при уходе в фон — пауза (для эфира — освобождение потока), при возврате — продолжение (эфир — с текущего момента);
  - поворот экрана не перезапускает поток.
- **Фаза:** P0
- **Статус:** 🟡 частично (сделано по всем критериям: экран не гаснет, эфир в фоне освобождается и при возврате начинается с текущего момента, поворот без перезапуска; освобождение в фоне на устройстве не проверено)

### PLR-003 Инфо-плашка
- **Суть:** при переключении канала и по OK/Info на несколько секунд появляется плашка с логотипом, номером и названием.
- **Пульт:** OK, Info, Menu, Guide. **Сенсор:** тап.
- **Критерии приёмки:**
  - время показа — из `Defaults`;
  - с P1 на плашке — передачи «до / сейчас / далее» (EPG-006).
- **Фаза:** P0
- **Статус:** ✅ есть (без телегида)

### PLR-004 Интерфейс движка воспроизведения
- **Суть:** экраны управляют воспроизведением через интерфейс ядра, а не через ExoPlayer напрямую.
- **Критерии приёмки:**
  - текущее поведение PLR-001…003 сохранено после перехода на интерфейс;
  - один сеанс воспроизведения переживает переход «превью → весь экран → плеер в углу» без перезапуска потока;
  - есть тестовая реализация движка для unit-тестов логики плеера.
- **Фаза:** P0
- **Статус:** 🟡 частично (интерфейс в `core`, реализация на ExoPlayer, тестовый движок, один сеанс выше экранов, переключение экрана видео без перезапуска; превью и плеер в углу появятся в P1/P3; поведение после перехода на устройстве не проверено)

### PLR-005 Запасные варианты и время отказа
- **Суть:** неоткрывшийся поток перебирает варианты: другой формат (HLS ↔ MPEG-TS) и другой движок, каждый по разу.
- **Сценарий:** канал не открылся в ExoPlayer — через пару секунд он играет в запасном движке, пользователь ничего не нажимал.
- **Критерии приёмки:**
  - общее время перебора ограничено настройкой «Сдаться через»: 15 / 30 / 60 с / никогда, по умолчанию 30 с; ожидания, которые просит сам провайдер, не считаются;
  - по исчерпании — понятное сообщение и запись в журнал (PLR-025), а не вечный спиннер;
  - удачный вариант для канала эфира запоминается; для фильмов не запоминается — каждый фильм стартует с выбранного движка;
  - если канал часто теряет кадры, плеер предлагает попробовать другой движок.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-006 Восстановление при обрыве
- **Суть:** при обрыве эфира плеер сам переподключается.
- **Критерии приёмки:**
  - при остановке потока остаётся последний кадр; через ~10 с — сообщение о потере сигнала и о том, что идёт повторное подключение;
  - повторы с нарастающей паузой, число попыток — настройка;
  - картинка возвращается сама, когда сеть восстановилась;
  - при отказе провайдера из-за лимита подключений — обратный отсчёт и автоповтор (SRC-022).
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-007 Панель управления
- **Суть:** скрывающаяся панель с перемоткой и кнопками.
- **Пульт:** OK — показать/скрыть; Back — сначала скрыть панель, затем выйти; при скрытой панели у фильма ◀▶ — перемотка на шаг (удержание — непрерывно). **Сенсор:** тап — показать/скрыть, двойной тап по краю — перемотка на шаг.
- **Критерии приёмки:**
  - полоса перемотки с предпросмотром времени; предыдущий/следующий эпизод; пауза;
  - кнопки: аудио, субтитры, скорость (0,5–2×), масштаб и формат кадра (вписать, заполнить, растянуть, исходный, 16:9, 4:3), громкость и выключение звука, избранное, сведения о потоке, качество (если вариантов несколько);
  - часы всегда видны (при архиве — CU-007);
  - шаг перемотки — настройка (по умолчанию 10 с);
  - масштаб и громкость запоминаются для элемента; сброс — SET-009;
  - у каждой кнопки при фокусе видна подпись.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-008 Аудиодорожки
- **Суть:** выбор звуковой дорожки на лету.
- **Критерии приёмки:**
  - у дорожки — язык, кодек, число каналов;
  - переключение без перезапуска потока.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-009 Встроенные субтитры
- **Суть:** текстовые (SRT, ASS, WebVTT), графические (PGS, VobSub, DVB) и скрытые субтитры (CEA-608/708).
- **Критерии приёмки:**
  - все дорожки видны в выборе с языком; «Выключены» — отдельный пункт;
  - скрытые субтитры работают и в эфире.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-010 Оформление субтитров
- **Суть:** шрифт, размер, цвет, положение и подложка субтитров.
- **Критерии приёмки:**
  - вариант «как в файле» сохраняет авторское оформление;
  - если размер на разных движках выглядит по-разному, он хранится для каждого движка отдельно;
  - изменения видны сразу на примере.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-011 Субтитры из файла и синхронизация
- **Суть:** подключение файла субтитров с устройства или USB и сдвиг субтитров во времени.
- **Пульт:** в меню субтитров строка сдвига: ◀▶ на 0,1 с, OK — обнулить.
- **Критерии приёмки:**
  - выбор файла без интернета и без учётной записи;
  - сдвиг применяется сразу; поиск субтитров в сети — META-008.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-012 FFmpeg-аудио для ExoPlayer
- **Суть:** программный декодер звука для форматов, которые устройство не декодирует само (DTS, TrueHD, иногда AC3/E-AC3).
- **Критерии приёмки:**
  - переключатель в настройках звука, по умолчанию выключен; включается и автоматически как шаг запасной цепочки (PLR-005);
  - фильм с DTS-дорожкой на устройстве без DTS-декодера играет со звуком.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-013 Предпочитаемые языки
- **Суть:** язык звука и субтитров выбирается автоматически.
- **Критерии приёмки:**
  - настройка профиля: список языков; для звука дополнительно «язык оригинала» (по TMDB, иначе основная дорожка);
  - ручной выбор дорожки (в том числе «субтитры выключены») запоминается для канала, фильма или сериала в профиле.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-014 Объёмный звук
- **Суть:** «Авто» / «Только стерео» / «Многоканальный», передача Dolby/DTS без декодирования.
- **Критерии приёмки:**
  - «Авто» пытается многоканальный вывод и при сбое вывода (тишина, ошибки, повторяющиеся опустошения буфера) переходит на стерео до конца сеанса, без перезапуска позиции;
  - переключатель «Передавать Dolby/DTS на ресивер»; при включённых ночном режиме или выравнивании звук декодируется в приложении.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-015 Громкость и обработка звука
- **Суть:** ночной режим (сжатие динамики), выравнивание громкости между каналами, усиление до 150% с мягким ограничителем, громкость по умолчанию.
- **Критерии приёмки:**
  - всё по умолчанию выключено; громкость по умолчанию 100%;
  - усиление выше 100% не даёт клиппинга на тестовом сигнале.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-016 Синхронизация звука
- **Суть:** сдвиг звука относительно картинки.
- **Пульт:** в меню звука ◀▶ с шагом 25 мс.
- **Критерии приёмки:**
  - «Запомнить для этого элемента»; общий сдвиг в настройках;
  - отдельная задержка для текущего устройства вывода (HDMI, ARC, Bluetooth, динамики ТВ, наушники) хранится для каждого вывода;
  - работает и при передаче звука без декодирования.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-017 Смена движка для элемента
- **Суть:** кнопка на панели плеера переключает текущий канал или фильм на другой движок и запоминает выбор.
- **Сценарий:** канал заикается в ExoPlayer — одно нажатие, и он играет в альтернативном движке, в следующий раз тоже.
- **Критерии приёмки:**
  - кнопка показывает движок, который играет сейчас; скрыта, если альтернативный движок не собран или элемент защищён DRM;
  - выбор для элемента важнее общей настройки;
  - «Сбросить выбор движков» в настройках забывает все такие выборы.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-018 Порядок движков
- **Суть:** для эфира и для видеотеки отдельно: «основной, затем запасной», «запасной, затем основной», «только основной», «только запасной».
- **Критерии приёмки:**
  - варианты «только» отключают автоматический переход;
  - переопределяется для отдельного источника (SET-010);
  - без собранного альтернативного движка настройка показывает только доступные варианты.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-019 Защищённые потоки (DRM)
- **Суть:** Widevine и ClearKey для DASH и HLS по данным из плейлиста (`#KODIPROP`: сервер лицензий или ключи `kid:key` прямо в плейлисте).
- **Критерии приёмки:**
  - пользователю ничего не нужно настраивать;
  - такие элементы всегда играют в ExoPlayer, не уходят во внешний плеер и не записываются (CU-014);
  - если устройство даёт только SD, это не считается ошибкой приложения;
  - источник, добавленный до поддержки DRM, получает ключи после обновления.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-020 Определение контейнера по ответу
- **Суть:** формат потока определяется по объявленному типу, затем по фактическому содержимому ответа, затем по тому, что этот провайдер уже отдавал.
- **Критерии приёмки:**
  - DASH- и HLS-потоки без расширения в адресе играют;
  - для Xtream и Stalker, где адрес не говорит о формате, используется тот же механизм.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-021 Буферизация и сеть
- **Суть:** настройки для слабых каналов связи.
- **Критерии приёмки:**
  - «Задержка эфира» (близость к краю эфира) реально меняет размер буфера; «Предбуфер» — выкл / 2 / 5 / 10 с перед стартом;
  - для фильмов и архива: размер буфера, таймаут сети, число переподключений (варианты «авто»);
  - задержка, предбуфер и «сдаться через» переопределяются для источника.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-022 Качество и декодирование
- **Суть:** аппаратное декодирование, программное выше 1080p по выбору, предпочтение SDR, максимальное качество, туннельный режим.
- **Критерии приёмки:**
  - аппаратное декодирование по умолчанию включено; при испорченной картинке — автоматический переход на программное;
  - 4K/8K без аппаратного декодера не запускается программно (если не включено явно) — понятная ошибка вместо зависания;
  - «Максимальное качество» ограничивает выбор варианта в адаптивном потоке; кнопка «Качество» выбирает вариант для текущего просмотра;
  - туннельный режим показывается только там, где декодер его поддерживает, и выключается после первого сбоя.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-023 Частота кадров и разрешение экрана
- **Суть:** по выбору экран переключается на частоту кадров видео; для фильмов — и на его разрешение.
- **Критерии приёмки:**
  - по умолчанию выключено; системная настройка Android TV о частоте важнее настройки приложения;
  - если поток не сообщает частоту, она измеряется и применяется, только если два замера совпали;
  - для фильмов: пауза на время переключения экрана (выкл–5 с) и совпадение разрешения, не выше родного у ТВ.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-024 Сведения о потоке
- **Суть:** экран с техническими данными текущего воспроизведения.
- **Критерии приёмки:**
  - кодеки, разрешение, частота кадров, глубина цвета, тип HDR, битрейт, декодер, звук, заполнение буфера, потерянные кадры, движок;
  - адрес потока показан со скрытыми логином и паролем;
  - измеряемые значения (фактический битрейт, кадры) — по настройке.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-025 Журнал ошибок
- **Суть:** последний сбой приложения и история ошибок воспроизведения, переходов на запасные варианты и отказов.
- **Критерии приёмки:**
  - сбой пишется на диск в момент падения и виден после перезапуска;
  - экспорт в текстовый файл в папку загрузок, пароли и токены в адресах скрыты;
  - переключатель подробного журнала для воспроизведения проблемы.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-026 Картинка в картинке и плеер в углу
- **Суть:** системный PiP при выходе на главный экран ТВ/телефона; внутри приложения — плеер в углу, который продолжает играть при навигации.
- **Критерии приёмки:**
  - выбор другого канала обновляет плеер в углу на месте;
  - размер и угол — одна настройка;
  - субтитры видны и в уменьшенном окне;
  - к плееру в углу можно вернуться из любого экрана через пункт «Сейчас играет» бокового меню.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-027 Только звук
- **Суть:** пользователь выключает картинку и слушает, продолжая пользоваться приложением; элементы без видео (радио) помечаются, а не считаются ошибкой.
- **Критерии приёмки:**
  - в шапке — компактная плашка с названием, временем и кнопками «Во весь экран» / «Стоп»;
  - радиоканал показывает метку «только звук» вместо чёрного экрана с ошибкой.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-028 Таймер сна
- **Суть:** остановка воспроизведения через 15–90 мин, в конце передачи или в конце фильма/эпизода.
- **Критерии приёмки:**
  - активный таймер виден на панели;
  - в конце эпизода по таймеру следующий эпизод не начинается;
  - опция «выключить экран» переводит ТВ в режим ожидания (с однократным запросом разрешения).
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-029 Медиаклавиши и системная интеграция
- **Суть:** плеер работает с медиасеансом системы и аудиофокусом.
- **Критерии приёмки:**
  - play/pause/следующий/предыдущий с пульта, гарнитуры и голосового ассистента;
  - уведомление другого приложения приглушает звук, а не ставит на паузу;
  - возврат после заставки: фильм на том же месте на паузе, эфир — на краю эфира.
- **Фаза:** P3
- **Статус:** ⬜ нет

### PLR-030 Внешний плеер
- **Суть:** воспроизведение в установленном внешнем плеере.
- **Критерии приёмки:**
  - отдельные переключатели для эфира, фильмов и сериалов;
  - при нескольких плеерах — выбор с «Всегда»;
  - фильм открывается во внешнем плеере с сохранённой позиции, если плеер это поддерживает;
  - пункт «Во внешнем плеере» есть в меню элемента и загрузки.
- **Фаза:** P3
- **Статус:** ⬜ нет
