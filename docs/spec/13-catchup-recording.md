# 13. Архив, буфер эфира и запись (CU)

Просмотр прошедшего из хранилища провайдера, пауза и перемотка эфира на устройстве, запись передач.

### CU-001 Признак архива у канала
- **Суть:** Fervo TV знает, у каких каналов есть архив и на какую глубину.
- **Критерии приёмки:**
  - Xtream: признак и глубина архива из данных канала;
  - M3U: атрибуты `catchup`, `catchup-days`, `catchup-source` (в том числе шаблоны со временем начала, длительностью, смещением);
  - Stalker: признак архива портала;
  - у таких каналов в строке, в сетке и в плеере — значок перемотки; категория «С архивом» (LIVE-010) содержит их все.
- **Фаза:** P4
- **Статус:** ⬜ нет

### CU-002 Просмотр прошедшей передачи
- **Суть:** прошедшую передачу можно посмотреть с начала с полной перемоткой.
- **Сценарий:** в сетке на прошедшей передаче «Смотреть с начала»; или в меню канала «Архив» → список передач по дням.
- **Критерии приёмки:**
  - доступно на глубину архива провайдера (обычно до 7 дней);
  - в плеере работает полоса перемотки по длительности передачи;
  - передачи вне глубины архива не предлагаются.
- **Фаза:** P4
- **Статус:** ⬜ нет

### CU-003 Перемотка эфира
- **Суть:** на архивных каналах можно отмотать назад прямо из эфира и вернуться к эфиру.
- **Пульт:** в панели управления — назад/вперёд и «К эфиру»; по настройке «Перемотка стрелками» ◀▶ во весь экран перематывают (удержание — непрерывно), иначе открывают панели LIVE-019/LIVE-020.
- **Критерии приёмки:**
  - шаг перемотки эфира настраивается отдельно от шага видеотеки;
  - после отмотки плашка показывает отставание от эфира; «К эфиру» возвращает к прямому потоку.
- **Фаза:** P4
- **Статус:** ⬜ нет

### CU-004 Переход к моменту
- **Суть:** «Вернуться к…» в плеере предлагает времена назад от текущего и точный выбор дня, часа и минуты.
- **Сценарий:** пользователь опоздал к началу матча на архивном канале без телегида и выбирает «19:00».
- **Критерии приёмки:**
  - работает без телегида;
  - выбор ограничен глубиной архива канала;
  - быстрые варианты — несколько ближайших получасовых отметок и вчерашний вечер.
- **Фаза:** P4
- **Статус:** ⬜ нет

### CU-005 Часовой пояс архива
- **Суть:** правильное время запроса архива у провайдера.
- **Критерии приёмки:**
  - варианты: автоматически (для Xtream — пояс сервера, читается при каждой синхронизации), пояс устройства, фиксированное смещение с шагом 15 мин;
  - по умолчанию «автоматически»; задаётся также для отдельного источника (SET-010).
- **Фаза:** P4
- **Статус:** ⬜ нет

### CU-006 Непрерывный просмотр архива
- **Суть:** по окончании передачи из архива начинается следующая; догнав настоящее время, плеер переходит в эфир.
- **Критерии приёмки:**
  - подчиняется настройке автопродолжения (VOD-009);
  - если провайдер прекращает отдавать ещё идущую передачу, плеер переходит в эфир, а не замирает.
- **Фаза:** P4
- **Статус:** ⬜ нет

### CU-007 Два времени при просмотре архива
- **Суть:** в плеере видно время выхода передачи в эфир и текущее время.
- **Критерии приёмки:**
  - часы плеера показывают обе отметки, подписанные;
  - на инфо-плашке — передача «тогда» и передача, идущая сейчас.
- **Фаза:** P4
- **Статус:** ⬜ нет

### CU-008 Пауза и перемотка каналов без архива
- **Суть:** по настройке канал, который смотрят во весь экран, сохраняется на устройство и воспроизводится из этой копии, поэтому его можно ставить на паузу и перематывать.
- **Сценарий:** зрителю позвонили — он ставит паузу на обычном канале и через 10 минут продолжает.
- **Критерии приёмки:**
  - по умолчанию выключено; глубина — 15/30/45/60 мин (по умолчанию 15);
  - на устройстве всегда остаётся не меньше 1 ГБ свободного места, при нехватке удаляется самое старое;
  - управление — как у архивного канала (CU-003); провал связи на полосе отмечен и перескакивается;
  - копия — единственное подключение к провайдеру; уход в список эфира с тем же каналом в превью копию не прерывает;
  - после ухода с канала копия хранится 5 мин: при возвращении — вопрос «продолжить с места / к эфиру» (или всегда/никогда по настройке); при просмотре другого канала дольше 2 мин копия удаляется; все копии удаляются при запуске приложения; время считается по реальным часам, включая сон;
  - каналы с архивом используют архив провайдера; DRM-каналы буфер не используют.
- **Фаза:** P5
- **Статус:** ⬜ нет

### CU-009 Запись эфира
- **Суть:** запись канала на устройство из сетки, из списка каналов и из плеера.
- **Сценарий:** в сетке «Записать» на будущей передаче — запись пройдёт по её времени с запасом; в плеере «Запись» — с текущего момента до остановки.
- **Критерии приёмки:**
  - перед началом показывается, что запись займёт подключение (с учётом лимита SRC-022);
  - во время записи у канала значок записи, в его меню — «Остановить запись»;
  - готовая запись — в «Загрузки → Записи» с длительностью, размером и путём к файлу;
  - запись идёт при свёрнутом приложении (foreground-служба с уведомлением).
- **Фаза:** P5
- **Статус:** ⬜ нет

### CU-010 Запись по расписанию
- **Суть:** запись канала на выбранный день и интервал без телегида.
- **Критерии приёмки:**
  - выбираются день, начало и конец; конец раньше начала означает следующий день;
  - пересечение с другой записью того же источника показывается до подтверждения;
  - ближайшая запланированная запись видна на вкладке записей.
- **Фаза:** P5
- **Статус:** ⬜ нет

### CU-011 Запись каждого показа
- **Суть:** правило «записывать эту передачу на этом канале каждый раз».
- **Критерии приёмки:**
  - совпадение — по названию передачи на канале; повторы с тем же временем не дублируются;
  - правила видны списком и удаляются.
- **Фаза:** P5
- **Статус:** ⬜ нет

### CU-012 Сохранение передачи из архива
- **Суть:** прошедшую передачу из архива провайдера можно скачать как запись.
- **Критерии приёмки:**
  - сохраняется ровно интервал передачи с запасом из настроек;
  - отображается в записях как обычная запись.
- **Фаза:** P5
- **Статус:** ⬜ нет

### CU-013 Надёжность расписания записей
- **Суть:** запланированные записи переживают перезагрузку устройства и перезапуск приложения.
- **Критерии приёмки:**
  - таймер, пропущенный из-за выключения, при следующем запуске либо стартует (если передача ещё идёт), либо помечается пропущенным с причиной;
  - системные будильники восстанавливаются после перезагрузки.
- **Фаза:** P5
- **Статус:** ⬜ нет

### CU-014 Защищённые каналы не записываются
- **Суть:** запись DRM-канала отклоняется сразу с объяснением.
- **Критерии приёмки:**
  - отказ до начала записи, без создания файла;
  - текст объясняет, что защиту установил провайдер.
- **Фаза:** P5
- **Статус:** ⬜ нет

### CU-015 Настройки записи
- **Суть:** запас до начала и после конца записи, «оставлять один поток свободным».
- **Критерии приёмки:**
  - запас по умолчанию 2 мин до и 5 мин после;
  - при включённом «оставлять поток свободным» запись, занимающая последнее подключение, не стартует без подтверждения.
- **Фаза:** P5
- **Статус:** ⬜ нет
