# 12. Телегид (EPG)

Откуда берётся программа передач, как она связывается с каналами и как показывается.

### EPG-001 Источники телегида XMLTV
- **Суть:** пользователь подключает один или несколько XMLTV-адресов; телегид не скачивается без его согласия.
- **Сценарий:** после импорта плейлиста Fervo TV предлагает одним нажатием подключить телегид, адрес которого указан в плейлисте; позже адреса добавляются в настройках.
- **Критерии приёмки:**
  - кнопка «Взять из плейлиста» подставляет адрес из заголовка M3U (SRC-008);
  - у каждого адреса: свой User-Agent, интервал обновления (как у источников, включая «каждые N дней»), время и итог последнего обновления;
  - если загруженный телегид не совпал ни с одним каналом — источник телегида это пишет, а сетка предлагает автосопоставление (EPG-005).
- **Фаза:** P1
- **Статус:** 🟡 частично (сделано в данных: несколько источников XMLTV со своим User-Agent, расписанием, временем и итогом обновления, в том числе «ни один канал не совпал»; адреса из плейлиста; экрана и кнопки «Взять из плейлиста» нет)

### EPG-002 Телегид Xtream
- **Суть:** для аккаунтов Xtream программа берётся с сервера провайдера, если XMLTV не подключён или не покрывает канал.
- **Критерии приёмки:**
  - для текущего и ближайших передач используется короткий EPG сервера (по запросу, с кэшем);
  - полный XMLTV сервера (`xmltv.php`) подключается как обычный источник EPG-001;
  - тексты в base64 декодируются.
- **Фаза:** P1
- **Статус:** 🟡 частично (сделано в данных: `xmltv.php` как обычный источник, короткий EPG по запросу с кэшем, base64; на тестовом аккаунте программы нет — проверены пустые ответы; экраны его ещё не запрашивают)

### EPG-003 Загрузка и хранение программы
- **Суть:** телегид скачивается и разбирается потоково, хранится только нужное.
- **Сценарий:** XMLTV на 300 МБ (в gzip — 30 МБ) импортируется на приставке без зависаний.
- **Критерии приёмки:**
  - сжатый файл распознаётся по содержимому, не по расширению;
  - сохраняются передачи только тех каналов, что есть в подключённых источниках;
  - «Дней программы» — от 1 до 14, по умолчанию 7: одно число задаёт, сколько скачивается, хранится и насколько далеко листается сетка;
  - прошедшие передачи хранятся только у каналов с архивом (в пределах глубины архива);
  - битый тег пропускается, остальная программа загружается;
  - сетка перерисовывается один раз по окончании обновления, а не во время него.
- **Фаза:** P1
- **Статус:** 🟡 частично (сделано: потоковая загрузка, gzip по сигнатуре, только нужные каналы, «дней программы» 1–14 / 7 с очисткой, прошлое — по глубине архива, битый тег пропускается, подмена одной транзакцией; тест — XMLTV 322 МБ без роста памяти, реальный XMLTV 447 МБ — 5 с на ПК; на приставке и с экрана настроек не проверено)

### EPG-004 Привязка каналов к телегиду
- **Суть:** канал находит свою программу по `tvg-id` (или ID Xtream), затем по нормализованному названию.
- **Критерии приёмки:**
  - нормализация названий та же, что для логотипов (регистр, ё→е, теги качества, знаки);
  - ручная привязка важнее автоматической и сохраняется при обновлениях;
  - привязки хранятся в профиле.
- **Фаза:** P1
- **Статус:** 🟡 частично (сделано в данных: tvg-id, затем нормализованное название, как у логотипов; ручная привязка важнее и переживает обновления; профилей ещё нет)

### EPG-005 Автосопоставление и ручная привязка
- **Суть:** для каналов без программы Fervo TV подбирает каналы телегида по похожести названий.
- **Сценарий:** в сетке «Сопоставить автоматически»: уверенные пары применяются сразу, сомнительные — в список на проверку; в меню канала «Привязать телегид» открывает выбор с самыми похожими вариантами вверху.
- **Критерии приёмки:**
  - обрабатываются только источники, показанные сейчас; 400 каналов — не дольше 5 с;
  - в окне проверки можно отметить «взять и логотип телегида»;
  - если пользователь ушёл из сетки, сопоставление продолжается, по окончании — сообщение, окно проверки ждёт при возвращении.
- **Фаза:** P1
- **Статус:** 🟡 частично (сделано в данных: подбор по похожести названий, уверенные пары сразу, сомнительные — с кандидатами, логотип телегида по выбору; 400 каналов — меньше 1 с в тесте; экранов нет)

### EPG-006 Сейчас и далее
- **Суть:** текущая передача с прогрессом и следующие передачи везде, где показан канал.
- **Критерии приёмки:**
  - в строке канала (LIVE-005), в окне превью (LIVE-006), на инфо-плашке плеера и в списке каналов поверх видео;
  - на инфо-плашке плеера: предыдущая, текущая и следующая передача;
  - при смене передачи сведения обновляются без действия пользователя.
- **Фаза:** P1
- **Статус:** 🟡 частично (сделано в данных: «сейчас / далее» с прогрессом для страницы каналов одним запросом, «до / сейчас / далее» для плеера, обновление при смене передачи; на экранах не показывается)

### EPG-007 Сдвиг времени телегида
- **Суть:** поправка на часовой пояс для телегида, выложенного в другом поясе: общая и для отдельного канала.
- **Критерии приёмки:**
  - шаг — 15 минут, диапазон ±14 ч;
  - сдвиг канала задаётся из его меню и важнее общего;
  - обновление телегида сдвиг не сбрасывает.
- **Фаза:** P1
- **Статус:** 🟡 частично (сделано в данных: общий сдвиг, сдвиг источника и канала, канал важнее; обновление не сбрасывает; экрана нет)

### EPG-008 Сетка программы
- **Суть:** таблица «каналы × время» с вертикальной линией текущего момента.
- **Сценарий:** пользователь открывает «Телегид» в боковом меню; сетка открыта на текущем времени.
- **Критерии приёмки:**
  - при открытии линия «сейчас» стоит примерно на трети ширины, слева видны уже прошедшие пару часов;
  - над сеткой — окно с видео выбранного канала и описание передачи под курсором (название, время, длительность, описание);
  - у канала: номер, логотип, название, значок архива;
  - пересекающиеся передачи рисуются друг за другом, не накладываясь;
  - листается без рывков на 1 000 каналов и 7 днях (строки и время подгружаются окнами);
  - в углу — подсказки кнопок (UI-010).
- **Фаза:** P1
- **Статус:** ⬜ нет

### EPG-009 Перемещение по сетке
- **Суть:** двухшаговая навигация: сначала выбирается строка канала, затем передачи в ней.
- **Пульт:** ▲▼ — каналы; OK или ▶ — войти в передачи строки; ◀▶ — по передачам; Back — выйти к каналам; долгий OK на передаче — её меню. **Сенсор:** вертикальная и горизонтальная прокрутка, тап — меню передачи.
- **Критерии приёмки:**
  - пустой промежуток без программы — отдельная ячейка «нет данных», ◀▶ пересекают её шагами по 30 мин;
  - меню передачи: «Напомнить» (будущая) или «Смотреть с начала» (прошедшая, с архивом), «Записать», «Смотреть канал», «В избранное»;
  - долгий OK на названии канала — меню канала (LIVE-011).
- **Фаза:** P1
- **Статус:** ⬜ нет

### EPG-010 Инструменты сетки
- **Суть:** строка кнопок над сеткой: день, к текущему моменту, категория, порядок, поиск, автосопоставление.
- **Критерии приёмки:**
  - «День» — выбор из доступных дней; «Сейчас» возвращает к текущему времени;
  - «Категория» — тот же список, что в разделе эфира, включая подборки;
  - «Порядок» — как у провайдера, А–Я, сначала с архивом, сначала избранные; там же «Показывать каналы без программы» и «Видео в окне» (вкл/выкл);
  - «Поиск» находит канал или передачу по названию и переносит к ним курсор.
- **Фаза:** P1
- **Статус:** ⬜ нет

### EPG-011 Окно видео в сетке
- **Суть:** перемещение по строкам не меняет то, что играет в окне; первый OK на канале включает его в окне, второй — во весь экран.
- **Критерии приёмки:**
  - используется тот же сеанс воспроизведения, что и в превью эфира (второй декодер не создаётся);
  - при выключенном видео в окне показывается логотип канала; если превью выключено в разделе эфира, в сетке оно тоже выключено.
- **Фаза:** P1
- **Статус:** ⬜ нет

### EPG-012 Несколько телегидов с приоритетом
- **Суть:** порядок источников телегида — их приоритет: верхний рисуется, нижние заполняют его пробелы.
- **Критерии приёмки:**
  - «Выше» / «Ниже» в меню источника телегида меняют порядок;
  - если два источника описывают один канал, в часы, где верхний пуст, берётся нижний.
- **Фаза:** P4
- **Статус:** ⬜ нет

### EPG-013 Логотипы из телегида
- **Суть:** переключатель у источника телегида «Брать логотипы каналов отсюда».
- **Критерии приёмки:**
  - логотипы телегида заменяют логотипы плейлиста для сопоставленных каналов;
  - каналы, для которых в телегиде логотипа нет, сохраняют прежний.
- **Фаза:** P4
- **Статус:** ⬜ нет

### EPG-014 Значки на передачах
- **Суть:** в ячейках сетки и в расписании канала видно: стоит запись, установлено напоминание, передачу можно посмотреть из архива.
- **Критерии приёмки:**
  - значки обновляются сразу после установки/снятия напоминания или записи.
- **Фаза:** P4
- **Статус:** ⬜ нет

### EPG-015 Напоминания о передачах
- **Суть:** «Напомнить» на будущей передаче; в назначенное время Fervo TV предлагает переключиться.
- **Сценарий:** за 5 минут до начала поверх любого экрана, включая плеер, появляется предложение переключиться.
- **Критерии приёмки:**
  - режим: спросить / переключить сразу / только уведомить; время упреждения настраивается (по умолчанию 5 мин);
  - напоминание срабатывает, даже если приложение свёрнуто (системное уведомление);
  - переживает перезапуск устройства;
  - снять напоминание можно из того же меню.
- **Фаза:** P4
- **Статус:** ⬜ нет

### EPG-016 Телегид порталов Stalker
- **Суть:** программа берётся из самого портала, если XMLTV не подключён.
- **Критерии приёмки:**
  - отображается в строках, превью, плеере и сетке так же, как XMLTV;
  - используется для архива портала (CU-001).
- **Фаза:** P4
- **Статус:** ⬜ нет
