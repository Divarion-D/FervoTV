# Fervo TV — функциональная спецификация: обзор

Этот каталог описывает, что должен уметь Fervo TV, в каком порядке это делать и как проверить, что
сделано. Документы пишутся по правилам [`CLEANROOM.md`](CLEANROOM.md); реализаторы работают только по ним и по коду
Fervo TV.

## Видение

Fervo TV — плеер для собственных IPTV-источников пользователя (M3U, Xtream Codes, Stalker/Ministra).
Приложение не содержит каналов, подписок и контента. Цель — быстрый, предсказуемый плеер, которым
удобно пользоваться с дивана одним пультом, а на телефоне — пальцем, и который выдерживает очень
большие плейлисты провайдеров (десятки тысяч каналов и сотни тысяч фильмов) без подтормаживаний.

## Платформы

| Когда | Платформа | Как |
|---|---|---|
| Сейчас | Android TV, Google TV, приставки | приложение `app-tv` (Compose for TV), управление пультом |
| Сейчас | Android-телефоны и планшеты | приложение `app-mobile` (Compose), сенсорное управление |
| Позже | Samsung Tizen, LG webOS, Linux | отдельные клиенты, которые повторяют поведение из этой спецификации и форматы данных ядра (см. [`01-architecture.md`](01-architecture.md)) |

До разделения на модули (фаза P0) оба варианта собираются одним APK, как сейчас.

## Принципы

1. **Пульт прежде всего.** Любое действие доступно с крестовины, OK, Back и, по желанию, цветных и
   цифровых клавиш. Фокус всегда виден с расстояния 3 м. Нет мест, где фокус теряется или
   «проваливается» под другой слой.
2. **Сенсор на телефоне — полноценный.** Тап, долгое нажатие и свайпы дают те же команды, что и пульт
   (единый слой команд ввода, см. UI-001). Раскладка выбирается по ширине экрана, а не по типу устройства.
3. **Сначала то, что уже есть.** Сохранённые данные (плейлист, телегид, логотипы, метаданные)
   показываются сразу; сеть только обновляет их в фоне. Без интернета приложение открывается и
   показывает последнее известное состояние, а не экран ошибки.
4. **Масштаб.** Списки постраничные, разбор источников потоковый, в памяти не держится весь каталог.
   Ориентир: 50 000+ каналов и 150 000+ фильмов на приставке с 2 ГБ ОЗУ.
5. **Понятные отказы.** Если что-то не работает, пользователь видит причину человеческими словами и
   следующий шаг («Повторить», «Сменить источник», «Открыть журнал»). Бесконечных спиннеров нет.
6. **Значения по умолчанию — в одном месте** (сейчас `Defaults.kt`), каждое настраиваемое значение
   имеет разумный дефолт и не требует настройки для первого запуска.
7. **Данные пользователя не уходят с устройства** без явного действия: нет облака и учётных записей
   Fervo TV; перенос — только по локальной сети или файлом.

## Глоссарий

| Термин | Значение в Fervo TV |
|---|---|
| Источник, плейлист | Одна подключённая учётная запись провайдера: M3U-ссылка или файл, аккаунт Xtream Codes, портал Stalker/Ministra |
| Канал | Элемент прямого эфира |
| Фильм, сериал, эпизод | Элементы видеотеки (VOD) |
| Категория | Группа элементов от провайдера (`group-title`, категория Xtream) |
| Подборка | Категория, созданная пользователем из элементов любых категорий |
| Телегид, EPG | Расписание передач (XMLTV, короткий EPG Xtream, EPG портала) |
| Передача | Одна запись телегида: канал, начало, конец, название, описание |
| Архив, catch-up | Возможность смотреть уже прошедшие передачи из хранилища провайдера |
| Локальный буфер эфира | Запись текущего канала на устройство для паузы и перемотки, если у провайдера нет архива |
| Движок | Реализация воспроизведения (Media3 ExoPlayer, ExoPlayer с FFmpeg-аудио, libmpv) |
| Превью | Воспроизведение канала в окне рядом со списком, без перехода во весь экран |
| Боковое меню | Вертикальная панель разделов у левого края экрана |
| Контекстное меню | Меню действий над элементом: долгий OK, клавиша Menu или долгое касание |
| Профиль | Набор личных данных зрителя: избранное, история, позиции, настройки показа |
| Лимит подключений | Сколько потоков одновременно разрешает аккаунт провайдера |
| Ввод с телефона | Заполнение формы на телефоне через QR-код и PIN вместо набора пультом |

## Формат записи функции

Разделы 10–32 состоят из записей одного вида:

```
### ПРЕФИКС-001 Короткое название
- **Суть:** одно-два предложения.
- **Сценарий:** как этим пользуются.
- **Пульт:** … **Сенсор:** … (если применимо)
- **Критерии приёмки:**
  - проверяемый пункт
- **Фаза:** P1
- **Статус:** ⬜ нет | 🟡 частично (что есть) | ✅ есть
```

- **ID** = префикс раздела + трёхзначный номер, нумерация с 001 без пропусков. ID не переиспользуется:
  если функция отменена, запись остаётся со статусом «отменено» и причиной.
- Префиксы: SRC (10), LIVE (11), EPG (12), CU (13), VOD (14), PLR (15), HOME (16), PROF (17),
  DL (18), MV (19), META (20), SPORT (21), UI (30), SET (31), BAK (32).
- **Критерии приёмки** проверяются вручную на устройстве или тестом; формулировка «работает хорошо» не
  допускается.
- **Статус** ставится по фактическому состоянию Fervo TV. ✅ — сделано (в том числе проверено только
  кодом и тестами, если это сказано в README); 🟡 — сделано частично, в скобках что именно есть;
  ⬜ — ещё нет.
- Ссылка на другую функцию — по ID (например, «см. EPG-007»).

## Фазы

| Фаза | Содержание |
|---|---|
| **P0 Фундамент** | Модули `core` / `app-tv` / `app-mobile`, база данных, потоковые парсеры, интерфейс движка воспроизведения. Всё, что работает сейчас, продолжает работать |
| **P1 Live TV + EPG** | Список каналов с превью, текущая и следующая передача с прогрессом, сетка программы с отметкой «сейчас», боковое меню, часы, подсказки кнопок, управление категориями, избранное |
| **P2 Видеотека и навигация** | Фильмы и сериалы, главный экран, поиск, история |
| **P3 Плеер** | Дорожки, субтитры, FFmpeg-аудио, журнал ошибок, PiP, DRM, смена движка для канала |
| **P4 Источники и архив** | Несколько плейлистов, Stalker, catch-up, напоминания |
| **P5 Люди и хранение** | Профили, PIN, детский режим, резервные копии и перенос, запись, загрузки, мультиэкран |
| **P6 Обогащение и оформление** | Метаданные, спорт, темы и акцентный цвет, настройка с телефона через QR, обновления |

Полный список ID по фазам и критерии готовности фаз — в [`90-roadmap.md`](90-roadmap.md).
